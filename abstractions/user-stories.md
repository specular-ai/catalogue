# User stories

[Catalogue](../README.md)

A structured model of user stories and their associated journeys or steps.

| Property | Description |
| --- | --- |
| Subject | Project |
| Purpose | Descriptive, constructive |
| Required models | [Semantic model](../models/semantic.md) |

## Developer question

What user journeys are defined in the system?

## Representation and interaction

Explore stories by actor or goal; inspect original story text; in an editable implementation, revise stories and review source updates.

## Information and evidence

Identifiable stories, actors, goals, journey relationships, and links to their source descriptions. The view should preserve navigation to supporting evidence and make unavailable information explicit.

## Example

An administrator’s story describes deleting an obsolete item, including the confirmation step and cancellation alternative.

This example is illustrative.

## Limitations

A story model describes intended use. It does not establish that a journey is implemented or tested.

## Scope

This entry describes an abstraction concept. It does not claim that a particular tool implements every interaction described here.
