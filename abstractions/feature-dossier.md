# Feature dossier

[Catalogue](../README.md)

A navigable feature brief collecting requirements, decisions, tasks, and expandable source excerpts.

| Property | Description |
| --- | --- |
| Subject | Project |
| Purpose | Descriptive |
| Required models | [Project model](../models/project.md), [Physical model](../models/physical.md) |

## Developer question

What is feature X about?

## Representation and interaction

Select a feature; expand related items and excerpts; navigate to the original documents.

## Information and evidence

Feature membership and source locations for the included items. The view should preserve navigation to supporting evidence and make unavailable information explicit.

## Example

The deletion feature dossier groups REQ-001, DES-003, and TASK-008 and shows the relevant portions of their documents.

This example is illustrative.

## Limitations

A brief can omit relevant material when feature membership is incomplete. Identify the scope and sources used.

## Scope

This entry describes an abstraction concept. It does not claim that a particular tool implements every interaction described here.
